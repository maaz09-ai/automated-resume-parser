# Automated Resume parser 

Automated Resume Parser

Description: Create a system to extract and categorize information from resumes (PDFs/Docs).

Technologies: Python (spaCy, PDFPlumber), Flask, PostgreSQL

Outcome: Extract candidate details (name, skills, education) and store them in a searchable database.
